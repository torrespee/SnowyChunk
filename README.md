# SnowyChunk v26.1.2

## Descripción
SnowyChunk es un plugin avanzado de protección de chunks para Spigot/Paper 1.13+.

## Instalación

1. Compila: `mvn clean package`
2. Copia el JAR a `/plugins/`
3. Reinicia servidor
4. ¡Listo!

## Comandos

- `/chunk help` - Ayuda
- `/chunk info` - Información
- `/chunk upgrade` - Mejorar
- `/chunk invite <player>` - Invitar
- `/chunk flag <flag> <true/false>` - Flags

## Características

✅ Sistema de 4 niveles
✅ Protección de chunks
✅ Flags personalizables
✅ Chat local
✅ Sistema de invitaciones
✅ Hologramas dinámicos
